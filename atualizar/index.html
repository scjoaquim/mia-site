// ATUALIZAR

Atualize o robô

Update the robot

Você recebeu um e-mail dizendo que saiu uma versão nova. É só baixar o arquivo e trocar o antigo — leva uns dois minutos. A sua chave de licença e o token do painel continuam os mesmos.

You got an e-mail saying a new version is out. Just download the file and replace the old one — it takes a couple of minutes. Your licence key and panel token stay the same.

⚠ Tem prazo. A versão antiga deixa de abrir operações 30 dias depois da publicação. O que estiver aberto continua a ser gerido até fechar — mas o robô não entra em novas. Depois de atualizar, tudo volta ao normal sozinho.

⚠ There is a deadline. The old version stops opening trades 30 days after publication. Whatever is open keeps being managed until it closes — but the robot enters no new trades. Once you update, everything resumes on its own.

// PASSO A PASSO

Quatro passos. Se o robô roda no VPS, o passo 4 é o que faz a versão nova chegar lá.

Four steps. If the robot runs on the VPS, step 4 is what gets the new version there.

01

Baixe o arquivo novoDownload the new file

Use o botão lá em cima. Se o navegador avisar que o arquivo é incomum, é esperado — ele não é assinado como um programa de loja.

Use the button above. If your browser warns that the file is uncommon, that is expected — it is not signed like a store application.

02

Troque o arquivo antigo pelo novoReplace the old file with the new one

No MetaTrader do seu computador, abra Arquivo → Abrir Pasta de Dados e entre em MQL5 → Experts. Cole o arquivo novo por cima do antigo — o nome é o mesmo, e o MetaTrader pergunta se quer substituir. Diga que sim.

In MetaTrader on your computer, open File → Open Data Folder and go to MQL5 → Experts. Paste the new file over the old one — same name, and MetaTrader asks whether to replace it. Say yes.

Não precisa tirar o robô do gráfico nem colar a chave de novo: o MetaTrader percebe que o arquivo mudou e recarrega o robô sozinho, com as suas configurações.

No need to remove the robot from the chart or paste the key again: MetaTrader notices the file changed and reloads the robot on its own, with your settings.

03

Confira que a versão nova está rodandoCheck that the new version is running

Na aba Especialistas, embaixo do gráfico, o robô escreve a versão ao arrancar. Se aparecer a versão desta página, está feito. Se o robô não aparecer no gráfico, feche e abra o MetaTrader.

In the Experts tab below the chart, the robot prints its version when it starts. If it shows the version on this page, you are done. If the robot is not on the chart, close and reopen MetaTrader.

Olhe também os outros gráficos abertos — o nome do robô aparece no canto de cima, à direita. Se o antigo ficou em algum deles, ele continua operando a mesma conta. Se achar um, me escreva antes de tirar: ele pode ter operações abertas.

Look at your other open charts too — the robot's name shows in the top-right corner. If the old one is still on any of them, it keeps trading the same account. If you find one, write to me before removing it: it may have open positions.

04

Roda no VPS? Migre de novoRunning on the VPS? Migrate again

O VPS tem uma cópia do seu MetaTrader — e ainda está com o arquivo antigo. Com o MetaTrader do computador já atualizado, clique com o botão direito na sua conta, no Navegador, e escolha Migrar. É o mesmo passo da instalação, e leva a versão nova para o servidor.

The VPS holds a copy of your MetaTrader — still with the old file. With MetaTrader on your computer already updated, right-click your account in the Navigator and choose Migrate. Same step as the installation; it carries the new version to the server.

Se não migrar, o robô do VPS continua na versão antiga — e é ele que opera.

If you do not migrate, the robot on the VPS stays on the old version — and that is the one trading.

Vale o mesmo lá: olhe os gráficos do VPS.

The same applies there: look at the charts on the VPS.

Alguma dúvida? Escreva para suporte@miats.trade. Se for a primeira instalação, a página é outra: Começar.

Questions? Write to suporte@miats.trade. If this is your first install, the page you want is Get started.
